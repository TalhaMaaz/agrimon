3 Problem

  • Mills: monitoring = manual field surveys, satellite-based per-field nahi
  • Milling cycle se pehle: yield ke hisab se planning aur price
  • Humara project: leadership ko field monitoring se faislay mein madad
  • 13-country map: Pakistan mein recall 43% (local labels nahi)
  • SUPARCO: satellite-based govt monitoring ka main idara, statistics ke liye

4 Aim

  • Web portal: digitised fields, crop labels, health history
  • Vigour (NDVI) vs normal cane cycle → health
  • Official yields + indices → regression → indicative yield
  • Disease diagnose nahi, sirf stress ke effects
  • Per-field yield dikhayenge, validate nahi: field-level ground truth nahi
  • NFRs: non-professionals ke liye aasan; modest hardware (laptop, Colab, Kaggle); map ~5,600 fields pe smooth

5 Interface

  • Date slider → purani images ka analysis
  • Mockup hai, asal results nahi

7 Research

8 Method

  • Pakistan mein zaroori open data nahi
  • SUPARCO aur Punjab study ke authors se contact kiya
  • Company: 8 lakh acres digitised (JDW ke 4.5 lakh samait); policy ki wajah se FYP mein use nahi
  • Iterative, Agile: plan, approve, build, review

9 Datasets

  • CSB boundaries; CDL labels: 95% producer's, 96% user's accuracy
  • Sentinel-2 images, NASS official yields
  • 18 seasons (2008–2025): temporal hold-out
  • La Réunion, Brazil, EuroCrops dekhe: kuch missing tha

10 Architecture

  • Sources: imagery, boundaries + labels, yield + weather
  • Ingestion: common interface (adapter pattern), source badla ja sakta hai
  • Common CRS, field = single unit, poori images store nahi
  • 3 models: crop, health, yield → web map (layers, slider, pop-up)

11 Use cases

  • Mill officer / agronomist: map, field click (crop, health, yield), date change
  • Developer: pipeline, models evaluate, naye regions ingest

12 Data model

  • Sab kuch FIELD se juda: labels, observations, predictions (saal-ba-saal)
  • REGION → FIELD: one-to-many; region ke official yield statistics

13 Tech stack

  • Open aur free: Python geo libraries, Planetary Computer
  • GeoParquet: column-based; humari files mein row = field
  • DuckDB: embedded (in-process) analytical DB, server nahi
  • Random Forest baseline → TempCNN, attention (PyTorch); MapLibre; Earth Engine optional

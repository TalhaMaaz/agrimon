# Foundation guide: index

Purpose: understand the ground the project stands on (the Claude Code kit, git, GitHub, the repository and the documentation system) before building anything. Issue #15.

Everything here was checked against the actual files and GitHub settings on 2026-10-10. Where the kit claims something that isn't true (yet), the lesson says so. Those mismatches are collected in [F6](F6_a_working_day_and_gaps.md#gaps-between-the-kit-and-reality).

## Reading order

Each part builds on the one before. Read one part, answer its check questions (in chat or in your own notes), then move on.

```
 F1  The big picture        four tools, one folder; "the repo is the memory"
  |
 F2  Claude Code in this kit   CLAUDE.md, commands, subagents, hooks, permissions
  |
 F3  Git as we use it        commits, branches, remote, our branch flow
  |

  |
 F5  The documentation system docs/, Obsidian, STATUS/HANDOFF/notebook, ADRs
  |

```

Run a teach-back on: $ARGUMENTS

1. Do NOT explain the concept first. Ask me to explain it in my own words, as if to an examiner, including the maths in plain language if the concept has any. Wait for my answer.
2. After I answer, grade it against `docs/concepts/`, `docs/learning/` and the code in this repo. List what was correct, what was missing, what was wrong. Be direct and specific.
3. Re-teach only the gaps, using plain words, a tiny worked example, then the formula and code if relevant.
4. Ask one follow-up question that tests the gap.
5. Update the understanding ledger (concept, date, result: not yet, shaky or solid) and save my explanation to `docs/learning/my_understanding/` only if I ask.
